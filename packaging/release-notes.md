Remote222 0.4.0 — вход по логину и паролю, без ручного переноса ключей в чат.

Скачайте **Remote222.exe**. В режиме **Через сервер очереди** введите адрес сервера, логин и пароль. Приложение запоминает вход на этом ПК; пароль на диск не записывается. При следующем запуске можно включить управление без повторного ввода пароля, пока сеанс действует.

Для подключения чата контроллер показывает ссылку и короткий код. Откройте страницу сервера в браузере, войдите и подтвердите подключение. Сеанс контроллера сохранится в рабочей среде: секрет `REMOTE222_TOKEN` и копирование длинных ключей для этого режима больше не нужны. После замены среды, отзыва или истечения сеанса потребуется новое подтверждение.

**Перед использованием обновите VPS:** [инструкция](https://github.com/teplydom12-boop/remote222/blob/main/docs/vps-account.md). Для VPS `95.163.231.24` используется имя `95-163-231-24.sslip.io`, указывающее непосредственно на сервер. Покупать домен не нужно. HTTPS по новому имени готов только после успешного обновления и выпуска сертификата; публикация EXE сама по себе сервер не обновляет.

**Отключить** и закрытие окна сохраняют вход, прекращая получение новых заданий. **Выйти из аккаунта** удаляет локальный вход и запрашивает отзыв сеанса на сервере; при недоступном сервере приложение сообщает, что отзыв не подтверждён. Уже начатая команда может завершиться. Новый сервер с настроенным аккаунтом отключает прежние статические ключи очереди. Прямой режим Cloudflare с прежним ключом сохранён.

Команды, вывод, ошибки, файлы и запрошенные снимки экрана передаются через очередь. Идентификаторы заданий и история защищают от повторного выполнения после потери ответа. Входящие порты на домашнем роутере, права администратора Windows и автозапуск не нужны.

Для публикации workflow запускает интеграционные проверки на Linux и Windows, собирает Windows EXE и выполняет самопроверку готового файла: Tk, Windows API, локальный агент, PowerShell, передача файлов, встроенный cloudflared, вход по аккаунту, подтверждение контроллера, повторный запуск с сохранённым сеансом и выход. В выпуск добавляются `Remote222.exe.sha256` и `windows-selftest.json`. Эти проверки не подтверждают доступность вашего VPS и рабочего стола; после подключения требуется свежий ответ Windows на `info`.

Приложение не подписано сертификатом издателя; Windows может запросить подтверждение запуска. Сетевой доступ к серверу должен быть разрешён в обеих средах; отсутствие HTTP 403 и других сетевых ошибок не гарантируется.
